# multiagent-tg

Мультиагентная команда в Telegram-группе. Каждый "коллега" — это отдельный Telegram-аккаунт (MTProto через [Telethon](https://docs.telethon.dev/)), его "мозг" — LLM (по умолчанию Google Gemini; альтернативно — Ollama / LM Studio / OpenAI / любой OpenAI-совместимый endpoint).

Они сидят в одной группе, видят друг друга, обсуждают задачи и **совместно делают сайты**: продакт собирает требования, дизайнер описывает UX, dev-агент пишет код в `./workspace/`, QA задаёт каверзные вопросы.

## ⚡ Быстрый старт (Windows)

1. Распакуйте архив.
2. Получите **Gemini API key** на https://aistudio.google.com/app/apikey («+ Create API key», free tier - ~1500 запросов/день).
3. Получите `api_id` и `api_hash` на https://my.telegram.org/apps (раздел "API development tools").
4. Двойной клик по **`start.bat`** - он сделает всё:
   - в первый раз автоматически вызовёт setup ^(uv + Python 3.11 + зависимости^)
   - спросит ваши `api_id` / `api_hash` / `Gemini API key`
   - залогинит Свету ^(придёт SMSкод^)
   - подскажет создать Telegram-группу и как узнать её id через `groupid.bat`
5. Впишите id группы в `.env`, снова **`start.bat`** — поехали.

Все остальные кнопки:
- `agents.bat` — список агентов и их статус
- `login.bat` — повторный логин или добавление новых аккаунтов
- `groupid.bat` — узнать id группы
- `doctor.bat` — проверить что LLM отвечает

## Что вам понадобится

- **Python 3.11+** (uv поставит автоматически, но если есть — лучше)
- **[uv](https://github.com/astral-sh/uv)** (или обычный pip)
- **1-4 Telegram-аккаунта** с реальными номерами телефонов. Лучше "тёплые" — не свежезарегистрированные. Можно стартовать с 1 ("Света") и добавить остальных позже.
- **API_ID и API_HASH** на https://my.telegram.org/apps — одна пара на всё приложение, не привязана к конкретному аккаунту.
- **LLM**: по умолчанию Google Gemini (ключ бесплатно на https://aistudio.google.com/app/apikey). Альтернативы: Ollama / LM Studio / OpenAI / любой OpenAI-совместимый endpoint.

## Установка вручную (Linux/macOS или если не хотите bat-скрипты)

```bash
# 1. Зависимости
uv sync          # либо: python -m venv .venv && .venv/bin/pip install -e .

# 2. (опционально) Локальная LLM вместо Gemini
# ollama pull qwen2.5:7b   # нужно ~5 ГБ, 16 ГБ RAM

# 3. Конфиг (интерактивный мастер)
uv run multiagent-tg init
# Спросит TG_API_ID, TG_API_HASH, LLM-провайдера (gemini/ollama/openai)
# и нужный API-ключ. Запишет .env.
```

Поправьте имена/номера/характеры в `config/agents.yaml`. На каждый телефон должен быть отдельный аккаунт.

## Первый запуск (по шагам)

### 1. Залогиньте всех агентов

```bash
uv run multiagent-tg login
```

Для каждого аккаунта будет интерактивно запрошен SMS-код, потом (если включена) — пароль 2FA. После успешного логина в `./sessions/` появятся `.session`-файлы — это и есть авторизация, в дальнейшем кодов больше не спросят.

Если хотите залогинить только одного:
```bash
uv run multiagent-tg login --only igor
```

### 2. Создайте Telegram-группу и добавьте туда всех агентов

Просто руками со своего личного аккаунта: создайте группу, добавьте каждого по @username или номеру.

### 3. Узнайте ID этой группы

```bash
uv run multiagent-tg group-id sveta
```

Покажет список всех групп/каналов, в которых состоит этот аккаунт. Найдите свежесозданную — впишите её id (отрицательное число) в `.env` как `TG_GROUP_ID`.

### 4. Запускайте

```bash
uv run multiagent-tg run
```

Теперь напишите что-нибудь в группу — например "Привет, ребят, нужен лендинг для кофейни" — и наблюдайте, как они начнут обсуждать.

Ctrl+C — выход.

## Как работает "решение, кто отвечает"

Когда в группу приходит сообщение:

1. **Если в нём явно упоминается агент по имени** (`Игорь, ...`, `Света, что думаешь?`) — отвечает именно он.
2. Иначе работает **роутер на LLM**: ему даётся последнее сообщение и список ролей, он выбирает одного или `none`.
3. **Анти-спам**: если один и тот же агент уже оставил `MAX_CONSECUTIVE_REPLIES` (по умолчанию 2) реплик подряд — он автоматом исключается из кандидатов.
4. Перед отправкой — случайная задержка `REPLY_DELAY_MIN..REPLY_DELAY_MAX` секунд + индикатор "печатает", чтобы выглядело по-человечески.

История чата (последние `CONTEXT_WINDOW` сообщений) хранится в SQLite (`./data/history.db`) и подаётся каждому агенту в контекст.

## Инструменты dev-агента

Игорь умеет:
- `write_file(path, content)` — создать файл внутри `./workspace/` (за пределы вылезти не может)
- `read_file(path)` — прочитать
- `list_dir(path)` — список содержимого
- `run_command(command)` — выполнить shell-команду из whitelist (`git`, `npm`, `npx`, `node`, `python`, `uv`, `ls`, `cat`, `mkdir`, `cp`, `mv`, `echo`, `touch`)

Стек он выбирает по задаче — Next.js для статичных лендингов, FastAPI+React для приложений с бэком, и так далее.


## Важные предупреждения

- **MTProto на пользовательских аккаунтах — серая зона.** Telegram может банить за автоматизацию, особенно свежие номера. Включённые задержки и анти-спам снижают риск, но не до нуля. Не используйте основной личный номер для агента.
- **Не комитьте `.env` и `sessions/*.session`** — там вся авторизация. `.gitignore` уже настроен.
- **Бюджет токенов:** на каждое входящее сообщение делается 1 LLM-запрос на роутинг и (если кто-то отвечает) ещё 1 на генерацию ответа. Если у Игоря включены инструменты — может быть до 5 раундов tool-calling. Для локальной модели это бесплатно, для OpenAI — следите за расходом.
- **Локальные модели:** для нормальной ролевой игры в группе нужно хотя бы 8B-14B параметров. На моделях меньше 7B качество диалога заметно проседает.
